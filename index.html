CSS Demo: Three Ways to Add Styles

External

External CSS

This card and paragraph are styled entirely by style.css, attached with a <link> tag.

Internal

Internal CSS

This box gets its orange border, background and italic text from the <style> block in this page's head. The card shape still comes from the external sheet.

Inline

Inline CSS

This paragraph uses the style attribute directly on the element. It wins over both the external rule (blue-grey) and any internal rule.

Which one wins?

MethodWhere it livesScopePriority
Inlinestyle="..." attributeOne elementHighest
Internal<style> in <head>One pageMedium
ExternalSeparate .css fileWhole siteLowest*

*With equal specificity, the rule that appears last wins. Inline styles beat selectors regardless of order (unless !important is used).
